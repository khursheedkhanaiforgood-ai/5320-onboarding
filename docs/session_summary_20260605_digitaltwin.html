Key Code — _group_id() fix

def _group_id(name: str) -> str:
    """ASCII-safe Dash component ID from a group name."""
    return 'chk-' + re.sub(r'[^a-z0-9]+', '-', name.lower()).strip('-')

Degraded RF Injection — How to Stress-Test the 12 Knobs

The problem: Lab AP (2 clients, clean RF) will always look "healthy." The optimizer will always recommend the same thing: enable WiFi 6 features. To test the knobs meaningfully, we need degraded RF conditions — high CRC, high CU, low SNR, interference — without going to a real stadium.

Five approaches (ranked by cost):

#MethodWhat it stressesCost
1iperf3 -c <client> -t 300 -P 8Tx/Rx CU, throughput saturationZero — use now
2Second AP on Ch 149 or Ch 11 nearbyinterference_cu_pct, ACSP neighbor costZero — already have it
3Wrap client in foil / move to range edgeSNR drop, weak_snr_threshold kicks inZero
4Synthetic DataStore injection (--inject scenario.json)Any field, fully controlled, repeatable1 day code
5HiveOS kdebug commandsPotentially CRC injection at kernel levelResearch needed

Recommended path: Implement synthetic injection (#4) first — define a set of "degraded scenario" JSON files (high-CU stadium, high-CRC interference, low-SNR edge) and replay them into DataStore. This lets us test the optimizer in software before touching real RF. Then layer in iperf3 (#1) for live RF stress tests and co-channel AP (#2) for interference testing. The synthetic mode also enables unit testing of the FederatedTwinAgent — you can assert "given this degraded input, the agent should recommend X knob change."

Console vs SSH for automated data collection

DimensionConsole (serial)SSH (Paramiko)
Baud rate115200 = ~14 KB/s~1 MB/s (LAN)
5-command poll feasibility~2 s per command = 10+ s total → exceeds 5 s poll intervalFull cycle in <1 s
Concurrent sessions1 (one serial cable)Multiple

Motivation for this document

The dashboard displays 35+ metrics. The simulator takes 60 parameters. To close the Digital Twin calibration loop, every input must be formally defined — its 802.11 clause, formula, valid range, and whether the AP can provide it or not. Without this reference, the FederatedTwinAgent has no authoritative source for what each field means or which 45 parameters must come from the DPM.
