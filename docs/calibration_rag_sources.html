§8 — How to Use These Sources in the RAG Pipeline

Phase 1 (now — pre-Sprint 3): Manual extraction. Read the 3 highest-priority documents (Cisco HD Design Guide 2025, Wi-Fi CERTIFIED 7 Overview, Extreme AP5060 stadium blog) and populate archetype_priors.md with min/max ranges for the 7 uncertain capMult() multipliers per archetype. One afternoon of work.

What to extract per document:

  • OFDMA DL gain at N clients (look for throughput improvement % vs baseline)
  • Airtime fairness gain (look for aggregate throughput improvement with mixed MCS clients)
  • MAC efficiency (look for "channel utilisation efficiency" or "throughput / PHY rate" ratio)
  • BSS Color gain (look for CCA improvement % in co-channel density)
  • MLO gain (look for latency reduction % and throughput increase vs single-link)

Phase 2 (Sprint 4+): Automated RAG ingestion using the existing xiq-ep1-intelligence-engine Playwright scraper pattern. Each URL above becomes a RAG corpus entry. The GP prior for each archetype gets seeded from the extracted min/max ranges. As AP3000 live data arrives, the posterior updates automatically.
