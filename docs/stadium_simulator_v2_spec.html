Toggles — 4 Multiplicative Correction Factors

Each toggle is ON/OFF in EP1. When ON, it applies a multiplier to the base airtime calculation in the simulator.

Toggle 1
OFDMA
Default: OFF — all 6 ax/be profiles
Stadium: ON
Simulator multiplier: DL ×1.35 / UL ×1.20. Orthogonal Frequency Division Multiple Access — lets one AP serve multiple clients per TXOP by splitting subcarriers. Most impactful single toggle for dense uplink (fan photo/video uploads).
Toggle 2
BSS Coloring
Default: OFF — all 6 ax/be profiles
Stadium: ON
Simulator multiplier: co-channel interference ×0.80 (20% reduction). Each AP marks frames with a colour ID — overlapping-cell clients suppress CCA deferral on other-colour transmissions. Critical for Lumen Field where 100+ APs share the same channels.
Toggle 3
MU-MIMO (DL + UL)
Default: DL ON (5G only) / UL ON (5G only)
Stadium: ON all bands (verify AP SKU)
Simulator multiplier: DL ×4 / UL ×2 spatial streams (AP5060). Multi-User MIMO — AP transmits to multiple clients simultaneously via beamforming. be-5G/be-6G support listed for AP5020/AP4020/AP4020X only — confirm AP5060 SKU support before enabling.
Toggle 4
TWT (Target Wake Time)
Default: OFF — all 6 ax/be profiles
Stadium: ON (be profiles, POS/IoT SSIDs)
Simulator effect: removes POS/IoT contention from shared airtime pool. AP schedules wake windows for POS terminals and IoT sensors — they only contend for the channel at their assigned slot. Frees unscheduled airtime for fan traffic.

Sliders — 8 Continuous Parameters

These reshape the capacity curve. Each becomes a range slider in the simulator UI, with a live recalculation on every drag.

Slider 1
Max TX Power (dBm)
Default: 20 dBm (2.4G) · 23 dBm (5G/6G)
Stadium: 17–20 dBm on 5/6 GHz
Drives cell radius → RSSI contour → spatial reuse count. Reducing TX power shrinks cells, enables more simultaneous non-interfering transmissions. Primary lever for per-AP client density. Range: 3–30 dBm.
Slider 2
Min TX Power / TPC Floor (dBm)
Default: 3 dBm
Stadium: 5–8 dBm
Prevents TPC from collapsing the cell below minimum coverage. Sets the guaranteed coverage floor in the simulator's link budget calculation. Range: 3–20 dBm.
Slider 3
SNR Threshold (dB)
Default: 15 dB (ax/be) · 20 dB (ac)
Stadium: 25 dB
Admission control boundary — clients below this SNR are rejected. Drives effective cell size and average MCS index in the simulator. Raising from 15 → 25 dB forces earlier roaming, raises average MCS, increases per-client throughput at the cost of tighter coverage. Range: 10–35 dB.
Slider 4
Max Clients per Radio
Default: 100
Stadium: 50–75
Hard capacity ceiling. When reached, AP rejects new associations — forces load-based roaming. Primary input to per-AP load calculation and system-wide capacity ceiling. Range: 10–200.
Slider 5
Channel Width (MHz)
Default: 80 MHz (5G) · 160 MHz (6G)
Stadium: 160 MHz (5G) · 320 MHz (6G, WiFi 7)
Input to the raw PHY rate lookup table (MCS × NSS × BW). 160 MHz doubles PHY rate vs 80 MHz. 320 MHz doubles again — WiFi 7 only on be-6G. Wider channels also mean fewer non-overlapping channels available; simulator must account for channel reuse penalty.
Slider 6
Band Steering Mode
Default: 80/20 Balanced (80% to 2.4 GHz)
Stadium: Encourage 5 GHz
Controls 2.4G / 5G / 6G client distribution ratio — the three independent airtime pools in the multi-band model. 80/20 Balanced is catastrophic for capacity: it steers 80% of clients to the lowest-capacity band. Encourage 5GHz inverts that ratio.
Slider 7
Airtime per Client Threshold (%)
Default: 0 (disabled)
Stadium: 5–10%
Airtime fairness enforcement. When enabled, no single client can consume more than this % of total radio airtime — prevents legacy 802.11g clients from hogging shared airtime. Adjusts per-client floor vs ceiling model in the simulator. Range: 0–50%.
Slider 8
Anchor Period (s)
Default: 60 s
Stadium: 30 s
Roaming aggressiveness — how long a client can stay associated before being steered. Shorter anchor = tighter RSSI distribution across the cell = higher average MCS index. Feeds the MCS distribution curve in the simulator. Range: 5–300 s.

8. Optional Settings — SSID-Level Parameters

These are SSID-level settings from the EP1 Optional Settings panel, separate from the radio profile. They govern legacy rate compatibility, security policy, roaming assistance, QoS enforcement, multicast handling, and client timers. All defaults shown as found in EP1.

PHY rate lookup — how bandwidth feeds the simulator: PHY rate (Mbps) = MCS index × spatial streams × coding rate × subcarrier count × bandwidth multiplier. 9. Power Control & Channel Selection

These are the two most consequential RF planning parameters — they determine cell size, co-channel interference, and spatial reuse. Separate from the EP1 Optional Settings panel: these are set in the Radio Profile (TPC) and in the AP Network Policy (channel plan).

9.1 — Transmit Power Control (TPC)

EP1 exposes both a manual max power and an automated TPC (Transmit Power Control) mode. For stadium density, both matter: manual max sets the upper bound; TPC algorithm steps down from there based on neighbour signal levels.

9.2 — Channel Selection & Planning

Channel assignment is set per-AP radio, either manually or via EP1's AutoRF DCS (Dynamic Channel Selection). For a 72K-seat stadium, the channel plan is as important as AP placement — a poor channel plan causes co-channel interference that no amount of TX power tuning can fix.

EP1 AutoRF uses Broadcom's DCS algorithm. Understanding the trigger thresholds is critical — misconfigured thresholds cause channel oscillation where APs flip channels back and forth every few minutes, worse than a bad static plan.

Oscillation risk: If the CCI and retry thresholds are set too close to the ambient values, DCS will continuously trigger channel changes that find marginally better channels — then the neighbour AP's DCS triggers in response, causing a chain reaction. Two new high-value parameters not yet in the spec:
MBR (Min Basic Rate): Raising from 6 Mbps → 24 Mbps is one of the most effective density tools — it physically shrinks the cell by refusing to serve weak clients. Simulator effect: adjusts effective cell radius independently of TX power.
RX-SOP: Sets the AP's CCI rejection floor. Default is typically −82 dBm. For high-density, drop to −75 dBm — AP ignores any frame from a source weaker than that, preventing far-away interference from triggering backoff. Simulator effect: adjusts co-channel interference correction factor.
