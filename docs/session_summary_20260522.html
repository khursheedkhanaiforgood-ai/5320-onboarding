NotebookLLM Integration

Nodes 0 and 11: Safety Rules and Cross-Validation Schema

The 8 am and 9 am NotebookLLM dialogues (May 22) validated the 17-agent LangGraph architecture without modification and produced two concrete JSON configs now living in sprint_b/.

Node 0 — Path Planner

scli_safety_rules.json — 7 CLI Guard Rules

These rules intercept the CLI delta before Node 0 writes any commands to the deployment queue. All seven were confirmed by actual lab incidents from May 6–8 2026.

G-01BLOCK_DELTAenable dhcp — not idempotent on EXOS; hangs XIQ at 15% on re-run
G-02BLOCK_DELTAenable ipforwarding — same hang condition; must be run manually post-factory-reset only
G-03OVERRIDE_TO_COMPLETEsystem antenna-type / environment — must always use complete variant
G-04STRIP_FROM_DELTAshow / display / get / debug / monitor — read-only commands, never enter deployment delta
G-05WARN + CONFIRMVLAN/policy create/delete overlaps with XIQ GUI — require explicit operator confirmation
G-06BLOCK + REWRITEVLAN underscore names dropped by XIQ (Guest_100 → Guest100)
G-07BLOCK + REWRITE${vlan:NAME} resolves to VLAN ID not name — EXOS rejects; always hardcode VLAN name

Node 11 — Cross-Validation Agent

cross_val_prompt.json — Multimodal XIQ ↔ EP1 Comparator

Invoked after both Sprint B (XIQ scrape) and Sprint C (EP1 scrape) complete. Claude receives a pair of screenshots — one per portal — plus the extracted field lists for each bin, and outputs a structured verdict per bin.

  • mapping_confirmation: CONFIRMED / RESTRUCTURED / GAP
  • c_gui: confidence score 0.0–1.0
  • neo4j_update: MAPS_TO / RESTRUCTURED_IN / MISSING_IN edge to write into the knowledge graph
  • field_mappings[]: per-field XIQ label ↔ EP1 label pairs
  • workflow_changes[]: notes on EP1 flow differences (e.g. wizard vs flat form)

Version pair format: XIQ-25.10.0__EP1-25.10.0

Sprint B Scrape

31 Bins Traversed — 196 Fields Extracted

The Playwright traverser (sprint_b/traverser.py) completed a depth-first walk of all 31 XIQ Classic GUI bins. For each bin it: navigated via the Dojo SPA side-nav (JS click to bypass Pendo and EP1 shell-content overlays), opened the Add/Edit modal where fewer than 5 list-page fields were detected, extracted all visible fields with a 6-strategy JS label resolver, and saved two screenshots (list page + form state).

Final corpus: 196 fields across 31 bins — 109 form fields + 87 list-page fields. 51 screenshots saved to sprint_b/output/screenshots/. Written to sprint_b/output/gui_baseline_xiq.json.

GUI Baseline Report

NYT-Style HTML Report with Live Client-Side Search

Deliverable

Generated by python3 -m sprint_b.generate_report. All screenshots are base64-embedded so the file is fully self-contained. Click any screenshot to toggle full-size. The Markdown version (xiq_gui_baseline_report.md, 24 KB) is ready for direct NotebookLLM upload.

Report Features

  • Masthead: NYT-style 3px top rule, Libre Baskerville serif title, XIQ version dateline
  • Sticky nav: amber-accented dark bar with quick-jump links to every bin (B01–B31)
  • Live search (sticky, always visible): searches across all 196 fields simultaneously — label, field type, nav path, bin name, placeholder text, and dropdown options
  • Instant results panel: shows bin → nav path → label → type → options; matched terms highlighted in yellow; click any row to scroll-jump to that bin
  • Per-bin sections: category badge, meta table (nav + route + field counts), screenshots grid, full field table with source badges (form / list)
  • Stats strip: 196 fields / 31 bins / 109 form / 87 list / 51 screenshots
